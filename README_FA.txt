بانک اطلاعات مربیان فردیس - نسخه ۱.۰
====================================

این نسخه برای ثبت و ارزیابی اولیه مربیان و فعالان فرهنگی و هنری است.
در این نسخه هیچ فیلدی برای کد ملی یا مدارک هویتی وجود ندارد.
اطلاعات شامل مشخصات تماس، تخصص، تحصیلات، سوابق، زمان همکاری، وضعیت بررسی و فایل رزومه است.

نکته مهم:
این بسته هنوز فایل Setup.exe نیست؛ سورس برنامه و فرایند ساخت خودکار فایل نصب ویندوز را دارد.
برای ساخت خروجی، نیازی به نصب پایتون روی رایانه شخصی شما نیست؛ GitHub Actions برنامه را روی یک ویندوز ابری می‌سازد.

روش ساخت Setup.exe بدون نصب پایتون روی رایانه شما:
۱) یک حساب GitHub بسازید یا وارد حساب خود شوید.
۲) یک Repository جدید و خالی بسازید.
۳) فایل‌های همین پوشه را در Repository بارگذاری کنید؛ پوشه مخفی .github نیز باید بارگذاری شود.
۴) از زبانه Actions، گردش کار Build Windows installer را اجرا کنید (یا پس از بارگذاری روی شاخه main خودکار اجرا می‌شود).
۵) پس از اتمام موفق، در صفحه اجرای workflow بخش Artifacts، فایل BankMorabianFardis-Windows-Installer را دریافت کنید.
۶) ZIP دریافتی را باز کنید و BankMorabianFardis-Setup.exe را اجرا کنید.

اطلاعات برنامه:
در ویندوز در مسیر زیر نگهداری می‌شود:
%LOCALAPPDATA%\BankMorabianFardis

برای انتقال به رایانه دیگر یا نگهداری امن، از دکمه «تهیه نسخه پشتیبان» استفاده کنید.
پیش از ورود اطلاعات واقعی، ابتدا با چند پرونده آزمایشی عملکرد نسخه را بررسی کنید.
